# Hunter System

A habit tracker with daily quests, XP, levels, ranks, graded sleep and weekend challenges.
It is a single-page web app that installs to a phone home screen and works offline.

Progress is stored on the device. Use Setup > Data to copy or restore a backup.

## Credits

The hunter's body (`hunter.bin`) is generated by `tools/gen_body.py` from the MakeHuman base mesh, morph targets,
rig joints and weights, which the MakeHuman project releases under CC0. 3D rendering uses three.js (MIT).
